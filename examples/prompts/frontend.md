# Frontend

Ubah hanya `examples/task_manager/static/`. Ikuti kontrak API. Implementasikan daftar, pembuatan, pengeditan judul dan deskripsi, tombol selesai, penghapusan, status pemuatan, dan status kesalahan. Gunakan `fetch` dengan origin yang sama; tampilkan masukan pengguna melalui `textContent`, jangan pernah menyisipkan nama tugas ke `innerHTML`. Jangan ubah API atau basis data. Catat langkah verifikasi browser yang benar-benar dilakukan.
