# Paket sumber pembaca Herdr Multi-Agen

Versi: 1.0.0

Paket pendamping ini berisi contoh yang dapat dijalankan, tes, prompt, dan petunjuk ringkas untuk *Orkestrasi Agen AI dengan Herdr*. Teks buku berbayar tidak disertakan.

## Instalasi dan tes

Gunakan Python 3.12 dari direktori akar repositori:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q tests
```

Hasil yang diharapkan: 42 tes lolos. Paket ini untuk digunakan bersama contoh buku. Hak publikasi dan lisensi khusus edisi Indonesia dijelaskan di `resource-manifest.json`; jangan menganggapnya sebagai lisensi sumber terbuka umum.

Lihat [`examples/README.md`](examples/README.md) untuk pemetaan bab, cara menjalankan situs web, dan panduan latihan. Lihat [`CHANGELOG.md`](CHANGELOG.md) untuk riwayat rilis.
